# Audit, 2026-11-17

Second audit, after the fixes of 2026-11-15 (PR #6). Five auditors read the
whole repository; this page lists what they found, who fixes it, and what is
left for the owner.

Rules for the fixes: no new dependencies (crates already in `Cargo.lock` may
become direct dependencies of another workspace crate), no Docker, LibreOffice
tests run one at a time, every fix gets a test that fails before it or a
written reason why it can't.

### Left open by wave 1

- macOS: tagged strays that are Apple platform binaries hide their
  environment, so the stray hunt can't see them; Python workers are found.
- macOS process cap is a fork-bomb guard on the user's total, not a per-job count.
- Seccomp, the Linux stray hunt and the engine grant probe ran on Linux in CI
  (run 44260848262, 2026-11-18) and passed; other distributions are untested.
- Redaction tracks words of three or more characters under a box; a common
  short word also removes any bookmark or label containing it.
- Remove hidden details now always removes files embedded in Office documents
  (a chart's workbook, an inserted file); what they show on the page stays.
  JPEG ICC profile names and Matroska image attachments are not cleaned yet.
- Redaction has no keyboard path for non-text areas (pictures); terms, words,
  lines and whole pages work by keyboard.
- A job cancelled while it is being created may stay in the store as cancelled.
- app-core's file workers should call `kill_job_strays` when they end (wave 2).

## Findings

### Security

- SEC-1: a verified output can change between verification and save. Record
  its SHA-256 and check it while copying.
- SEC-2: on macOS a worker can double-fork a daemon that outlives the job.
  Tag workers with `LFCS_JOB` and kill tagged strays after each job.
- SEC-3: the disk limit must cover the whole job folder, also while the worker is idle.
- SEC-4: no process-count cap on macOS.
- SEC-5: Linux has no seccomp filter. Write the cBPF filter by hand (libc only)
  and pass it with `bwrap --seccomp FD`; probe user namespaces first.
- SEC-6: size-limit the `/tmp` tmpfs (bubblewrap 0.9 or later).
- SEC-7: the engine allow-list checks the name only; check owner and permissions.
- SEC-8: no recheck job for Remove hidden details (file-clean, media-clean).
- SEC-9: the self-test doesn't probe what the engines are granted.
- SEC-10: `runtime_read` paths skip the `too_broad` check.
- SEC-11: preview PNG dimensions aren't checked before decoding.
- SEC-12: the output check trusts the worker's input page count.
- SEC-13: CLI password hygiene (without `zeroize`, a new dependency).
- SEC-14, SEC-15: low.

### Rust

- RS-2: a hidden job's `created` event leaks; a staging failure leaves the job.
- RS-3: `claim_file` evicts before its checks.
- RS-4: `redaction_params` drops invalid boxes silently; it must fail closed.
- RS-5: the stdin write blocks; use a writer thread.
- RS-6: a failed retry cleanup leaves a stale `out/`.
- RS-7: CLI `--skip-same`, `keep_folders` for `run`, help text.
- RS-8: `load` swallows errors.
- RS-9: share the scheduler's `open_regular`.
- RS-10: `checked_add` in sniffer `zip.rs`.
- RS-11: emit events outside the store lock.
- RS-13, RS-14: docs, a `Reason` macro, duplication, long functions.

### Privacy and Python

- PRIV-1: box-only redaction leaves text in ActualText, the structure tree,
  outlines, page labels, named destinations and threads; the verifier must
  check the captured text there too.
- PRIV-2: Office cleaning misses absPath, fileSharing, revision IDs,
  embeddings, customXml, printer settings, core title/subject, people.xml,
  document variables and permission ranges.
- PRIV-3: media cover art keeps its EXIF.
- PRIV-4: PNG and WebP should keep an allow-list of chunks; ICC profile descriptions.
- PRIV-5: disarm keeps non-web PDF `/URI`; the verifier needs a raw check.
- PRIV-6: PDF `/LastModified`, annotation `/M` `/T` `/NM`, trailer `/ID`.
- PRIV-7: optional content `/AS` arrays.
- PY-1: RecursionError and MuPDF overflow become retryable `E_INTERNAL`.
- PY-2: damaged streams give `E_OUTPUT_INVALID`.
- PY-3: missing cancel checks in long loops.
- PY-4: one shared `parse_xml`.

### Front end

- A11Y-1: reduced motion leaves infinite 1 ms animations.
- A11Y-2: redaction boxes need a keyboard path (a page-text line list).
- A11Y-3 to A11Y-20: focus, labels, control-border contrast (`--line-strong` 1.44:1), and more.
- UX-5: red banner while the self-test is still running.
- UX-6 to UX-11: Settings link, cancel while inspecting, confirm Start over,
  SchemaForm textarea newlines, registry retry, CLI hints in GUI text.

### Tests, CI, docs, release

- CI-2: nightly strace can't write its trace on Linux. CI-3: job timeouts.
  CI-4: clippy on all three systems. CI-6.
- TST-1: a floor on skipped tests; LibreOffice on macOS and Windows.
  TST-2: Windows network sampler. TST-3: timing-based tests.
- DOC-1: README `--dev` "coming" is stale. DOC-2: status statements.
  DOC-4: `troubleshooting.md`, `engines.md`.
- REL-1: bundle the worker runtime. REL-2: `release.yml` with unsigned
  artifacts and SHA256SUMS. REL-5: record engine versions. REL-6: CHANGELOG
  and a version check.

### Left open by wave 2

- CI-2, CI-3, CI-4, CI-6, TST-1, TST-2, DOC-1 to DOC-4, REL-1, REL-2, REL-5 and
  REL-6 are written; the bundled runtime and the release workflow have never
  run. The skip ceilings for macOS and Windows are estimates until their first
  run with LibreOffice installed.
- SEC-12 needs the check job to receive the original input (an ADR 0006
  change); it still takes the page count from the core's own inspection.
- SEC-8 covers file-clean; media-clean outputs need ffprobe in the check worker.
  The recheck re-reads with the same reader in a separate process.
- SEC-7 checks the engine binary, not its parent folders (Homebrew's are
  group-writable by design); on Windows only that it is a regular file.
- The worker libraries sit in the root `dev` dependency group; a `runtime`
  group would let the bundle script stop pruning test tools by name.
